# Tropa — фирменный стиль

**Название:** Tropa (по-русски «Тропа») — путь, который обходит препятствия.

## Цвета

| Роль | Цвет |
|---|---|
| Основной (primary) | `#534AB7` |
| Тёмный | `#3C3489` |
| Светлый | `#CECBF6`, `#AFA9EC` |
| Акцент (amber) | `#BA7517` |
| Приглушённый серый (выкл.) | `#5F5E5A` |

## Логотип

Скруглённый квадрат (радиус ≈ 22 % размера) цвета `#3C3489`, внутри — извилистая тропа
`#CECBF6` (скруглённые концы), ведущая снизу-слева к точке-цели `#AFA9EC` вверху по центру.

- `logo.svg` — основной логотип (для размеров от 48 px и крупнее, README, сайт).
- `logo-small.svg` — упрощённый вариант с более толстой линией и крупной точкой для 16/24/32 px.
- `tray-off.svg`, `tray-on.svg`, `tray-unchanged.svg`, `tray-pac.svg` — значки трея.

## Значки трея

Номер значка `NotifyIconN.ico` = `ESysProxyType + 1`. Глиф везде один, меняется только фон:

| Файл | Режим системного прокси | Фон |
|---|---|---|
| `NotifyIcon1.ico` | `ForcedClear` — прокси очищен / выключен | `#5F5E5A` серый |
| `NotifyIcon2.ico` | `ForcedChange` — системный прокси установлен | `#534AB7` фирменный |
| `NotifyIcon3.ico` | `Unchanged` — без изменений | `#3C3489` тёмный |
| `NotifyIcon4.ico` | `Pac` — PAC | `#BA7517` янтарный |

## Где лежат растровые значки

`v2rayN/v2rayN.Windows/Resources/*.ico`, `v2rayN/v2rayN.Desktop/Assets/*.ico`,
`v2rayN/v2rayN.Desktop/v2rayN.png`, `v2rayN/v2rayN.Desktop/v2rayN.icns`.
Имена файлов сохранены (в них остаётся `v2rayN`), ICO содержат размеры 16, 24, 32, 48, 64, 256.
Для 16/24/32 используется упрощённый вариант логотипа.

## Что не переименовано

Отображаемое имя — `Global.AppDisplayName` («Tropa»). Технические идентификаторы
(`Global.AppName` = `v2rayN`: пути конфигурации, автозапуск, резервные копии, имена процессов и
мьютексов, имена exe/сборок/архивов) остаются прежними для совместимости с upstream и обновлением.
